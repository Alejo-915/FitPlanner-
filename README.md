# 🏋️‍♂️ FitPlanner

**FitPlanner** es una aplicación web desarrollada con **FastAPI** que permite gestionar rutinas de entrenamiento, registro de usuarios, entrenadores y seguimiento del progreso físico.  
Forma parte del **Proyecto Integrador - Desarrollo de Software**.

---

## 📋 Descripción

FitPlanner tiene como objetivo facilitar la planificación y control de rutinas fitness mediante una API moderna y escalable.  
El sistema permite registrar usuarios, crear rutinas personalizadas, asignar entrenadores y almacenar métricas de progreso.

---

## 🧩 Requisitos

Antes de ejecutar el proyecto, asegúrate de tener instalado:

- Python 3.10 o superior  
- FastAPI  
- SQLModel  
- Uvicorn  
- Pydantic  
- SQLAlchemy  
- PyCharm Professional (opcional, para ver tablas y BD integradas)
